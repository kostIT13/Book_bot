# 📚 Book Bot - Telegram бот для чтения книг

Telegram-бот для удобного чтения книг с поддержкой закладок и постраничной навигацией.

## ✨ Возможности

- 📖 Постраничное чтение книг
- 🔖 Система закладок (добавление/удаление)
- ⏭️ Пагинация (вперед/назад)
- 🏠 Возврат к началу книги
- 📋 Список сохраненных закладок

## 🛠 Технологии

- Python 3.11+
- Aiogram 3.x (асинхронный фреймворк для Telegram Bot API)
- Pydantic (валидация конфигурации)
